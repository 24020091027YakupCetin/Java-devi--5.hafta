# Java Ödevi - 5. Hafta

Bu repository, Java Programlama dersi 5. hafta ödev kapsamında hazırlanan ArrayList, Nesne Yönelimli Programlama (OOP), Kalıtım (Inheritance) ve Matris işlemlerini içeren Java kodlarını barındırmaktadır.

## İçerik ve Problem Çözümleri

### 1. Distinct Elements & ArrayList (Main.java / Circle.java / Loan.java)
- Farklı türdeki nesneleri (Loan, Date, String, Circl`) tek bir ArrayList<Object> içerisinde toplama ve döngü kullanarak bu nesnelerin toString() metotlarını çalıştırma uygulaması.

### 2. Shuffle ArrayList (Arrays.java)
- Bir `ArrayList<Integer>` listesindeki elemanları rastgele karıştıran shuffle(ArrayList<Integer> list) metodunun uygulanması.

### 3. Extended Account Class (Account.java / Transaction.java)
- Müşteri adı ve işlem geçmişi (ArrayList<Transaction>) içeren gelişmiş Account sınıfı. Para çekme (withdraw) ve para yatırma (deposit) işlemlerinin tarih ve bakiye bilgisiyle kaydedilmesi.

### 4. Largest Rows and Columns
- n \times n boyutlu matrisi rastgele 0 ve 1 değerleriyle doldurup ekrana basan, ardından en çok 1 içeren satır ve sütunların indekslerini ArrayList kullanarak tespit eden program.

### 5. MyStack via Inheritance (MyStack.java)
- ArrayList<Object> sınıfından kalıtım (extends) alarak oluşturulan özel MyStack sınıfı ve kullanıcıdan alınan 5 metni ters sırada ekrana yazdıran test programı.
